# Anchorline UI Examples

This folder has simple example scripts for Anchorline UI.

The examples are meant to show how the library is used. They are not meant to control a real game by themselves. Replace the print statements with your own code when you build your own project.

## Files

```txt
basic.lua
components.lua
dashboard.lua
config.lua
```

## Recommended order

1. Start with `basic.lua`.
2. Open `components.lua` when you want to see more controls.
3. Use `dashboard.lua` if you want a more complete layout.
4. Use `config.lua` if you want to save and load control values.

## Quick tip

Keep your tabs simple. If one tab has too many controls, split it into two or three tabs.
